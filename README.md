# Project-Sign-up-form

A simple sign-up form project built with HTML and CSS.

## About the Project

This project is a recreation of a sign-up form layout from an original design. I focused on carefully calculating the size and spacing of elements while paying close attention to the details of the original file.

The goal was to practice building forms and improve my ability to accurately recreate a design using HTML and CSS.

## Built With

* HTML
* CSS

## What I Practiced

* HTML form controls
* Form structure and input elements
* CSS styling and positioning
* Element sizing and spacing
* Recreating an existing design accurately
